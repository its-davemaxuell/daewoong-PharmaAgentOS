**82 tests** across catalog, API, chat workspace and authorization; backend Ruff
passes for the changed files. Frontend lint, TypeScript checking and production
build pass. All **15 browser tests pass** across Chromium, Firefox and WebKit, including
**105 route/viewport combinations**, mobile focus return and 200% text scaling.
The Impeccable detector reported no findings on the main changed surfaces.
Docker Desktop's Linux daemon was unavailable locally; the PostgreSQL function

The browser work identified and corrected Firefox's intrinsic grid/input sizing
at 320px and WebKit's lack of pointer-focus on a clicked source button. Header
source links no longer start speculative library requests during unrelated tasks.
The suite checks the real Next application against a loopback-only fictional API,
not a standalone visual prototype. It generates an ephemeral test signing key,
explicitly overrides both backend-origin environment variables and never calls
production or a model provider. Existing backend tests verify ownership separately.

The browser matrix covers Home, Sources, Ask AI, Research and Approvals at
320/390/768/980/981/1024/1440px. Evidence-reader scenarios also run on a narrow
screen. Locale tests exercise both successful and failed approvals. Font-size
scaling is checked at 200%; this is not a substitute for a real-device or
screen-reader assessment or complete 400% reflow testing.

## Reproduction

```powershell
cd apps/web
npm ci
npm test
npm run lint
npm run typecheck
npm run build
npx playwright install chromium firefox webkit
npm run test:browser
```

For workspace-contained browser downloads, set `PLAYWRIGHT_BROWSERS_PATH` to
`C:/Users/user/Desktop/PharmaAgentOS/.artifacts/playwright-browsers` before installing
and running. The suite listens only on local ports 3100 and 8100 and stops its test
servers when it finishes. Backend tests use the existing project virtual environment.
