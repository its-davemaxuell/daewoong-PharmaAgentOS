# Visual UX refinement — September 12, 2026

## Scope and findings

The user requested an inspection and implementation with less text, more useful
visuals, larger typography and smooth transitions. Work stays in PharmaAgentOS.

The review found small navigation and control labels, repeated onboarding
instructions, text-only task choices and research setup competing with the
question. The original chat opening combined a 34px title with 12–14px controls
and examples. Source and review workflows needed a clearer visual introduction.

## Changes

- Chat shows a source → cited answer → human review diagram, a 32–48px heading,
  one short explanation and three visual task choices. Choices fill and focus an
  editable question; they do not submit it. Mobile uses full-width choice rows.
- The anchored composer uses 17–18px input, a short placeholder and an Options
  trigger with its full accessible label. Answers use 18px and original passages
  use 17px. Citation content, finding labels and request controls are preserved.
- Research uses larger question/input/status typography, compact topic choices
  and a three-step diagram. Evidence setup is a disclosure; its scope and selected
  passages remain visible. Selected passage/version identities are unchanged.
- Completed research now puts the brief before finished activity in DOM order,
  retaining citation inspection, exports and review labels. Active runs still
  prioritize current activity. This addresses the second visual review's finding
  that the result started below a full screen of completed work.
- Shared navigation uses 15px text (16px for primary tools), with larger existing
  icons. Supporting-page headings use 28–36px. Empty recent-chat copy and the
  redundant chat link are removed; all authorized destinations remain direct.
- One short diagram entrance and smooth interaction feedback accompany the
  existing route/panel transitions. Old staggered task-button entrances were
  removed after a screenshot exposed temporarily invisible choices. Reduced
  motion and the original all-menu animated preparation screen are retained.

The reference review included [Lusion](https://lusion.co/about/), whose award
record includes Site of the Year. [CSS Design Awards documents its 2023 win](https://www.cssdesignawards.com/blog/2023-website-of-the-year-winners/394/).
The application borrows the emphasis on prominent typography, visual explanation
and deliberate motion while retaining its established working interface.
